# 📄 User Onboarding Excel Sheet Submission Instructions

This directory (`docs/`) is designated for storing the exported Google Form user responses Excel sheet for **Rise In Level 5 - Blue Belt Submission**.

### File Name & Path:
- **`docs/user_onboarding_responses.xlsx`** (Excel format)

### Instructions for User:
1. Open your Google Form response dashboard.
2. Click **Export to Sheets / Download as .xlsx**.
3. Save the downloaded Excel file into `docs/user_onboarding_responses.xlsx`.
4. Commit the file to Git or keep it in the project root.
